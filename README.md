# Python Algorithmic Problem Solutions

A collection of Python scripts focused on solving various Data Structures and Algorithms (DSA) problems. These challenges primarily involve array manipulation, hash maps, sets, and core Python concepts.

## 📂 Repository Contents

### 📝 Algorithmic Solutions
* **`A website logs visitor IDs.py`**: Script to process and analyze visitor ID logs (likely utilizing arrays or sets for tracking).
* **`Detect Duplicate Transaction IDs.py`**: Algorithm to efficiently find duplicate entries in transaction records.
* **`Find All Numbers Appearing Exactly Once.py`**: Solution to isolate unique numbers/elements in a given dataset.
* **`Find Employees Present in Both Teams.py`**: Demonstrates finding the intersection of two different groups.
* **`Find Pair With Given Sum.py`**: Solution to the classic "Two Sum" problem to find pairs matching a target target.

### 🧠 Core Python Concepts
* **`tuple_unpacking.py`**: Demonstrates the mechanics, syntax, and use cases of tuple unpacking in Python.
* **`problmes_on_nonpd.py`**: Miscellaneous core Python problem-solving exercises.

### 📄 Supporting Data / Notes
* `question.txt`, `rat.txt`, `qwe.txt`, `Untitled-1.txt`: Supporting text files containing problem descriptions, sample input/output test cases, or scratchpad notes for the algorithmic challenges.
